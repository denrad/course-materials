# Материалы курса

Публичный сайт с готовыми презентациями, раздаточными материалами, кейсами и
полезными ссылками курса «Инструментальные средства разработки программного обеспечения».

Внутренние сценарии, черновики и преподавательские заметки в этот репозиторий
не переносятся.

## Как опубликовать материал

1. Подготовить финальную версию файла, безопасную для открытой публикации.
2. Положить её в `files/` в отдельную папку занятия, например
   `files/2026-01-programming-before-code/`.
3. Добавить на соответствующую карточку ссылку и дату публикации.
4. Просмотреть сайт локально и открыть pull request в `main`.

GitHub Pages собирает содержимое ветки `main` из корня репозитория штатным
способом после merge. Перед этим проверьте результат локально.

## Локальная сборка

Нужны Ruby 3.3.4, Bundler, Python 3.11+ и Make.

```sh
bundle install
make build
make serve
make test
```

`make build` создаёт сайт в `_site/`, `make serve` запускает локальный просмотр,
а `make test` собирает сайт во временный каталог и проверяет маршруты, карточки,
ресурсы и локальные ссылки. Эти же проверки выполняются в GitHub Actions; workflow
не публикует сайт.
