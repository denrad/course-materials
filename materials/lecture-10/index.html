Куда исчезли нули?

Три ошибки — три проверки

01
{"weight_grams": 1500
Синтаксис

Объект не закрыт.

02
{"weight_grams": "1500"}
Схема

Ожидалось число,
пришла строка.

03
{"weight_grams": 1.5}
Смысл

Отправитель имел в виду
1,5 кг. Поле — в граммах.

Что обнаружит парсер? Что — схема? Что требует знания задачи?

16 / 23

Что проверяет схема?

{
  "type": "object",
  "properties": {
    "weight_grams": {
      "type": "integer",
      "minimum": 1
    }
  },
  "required": ["weight_grams"]
}

Целое число
Строка "1500" не подходит.

Не меньше 1
Ноль не подходит.

Обязательное поле
Его нельзя пропустить.

services:
